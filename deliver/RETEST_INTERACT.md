# 手机端交互修复复测清单（Commit G = `8619e2c`）

安装 `android/Zhangxinchuang-public-v0.3.9.0.apk`（或从 GitHub `8619e2c` 构建）后按顺序复测。

## 准备
1. 覆盖安装 APK，打开「启动服务」。
2. 进入「守护」页。

## 复测项

### A. 守护标签保存按钮（原 Bug：标签点开无保存）
- [ ] A1 点任一标签（查岗拉回/情绪感知/主动提醒等），顶部导航条有「保存设置」按钮
- [ ] A2 修改任一数值（如查岗间隔）→ 点「保存设置」→ 提示已保存
- [ ] A3 杀掉 App 重开 → 数值保持
- [ ] A4 「全部设置」总页的「全局→保存设置」行为不变

### B. 课表删改（原 Bug：不能删除/更改）
- [ ] B1 课表作息 → 已有课程逐条列出；无课程时空态提示
- [ ] B2 录入两节课 → 列表出现两条
- [ ] B3 点某条「删除」→ 确认 → 该条消失，其余保留
- [ ] B4 点某条「修改」→ 弹出预填原值 → 改时间/科目保存 → 列表只剩新的一条（旧条目不残留）
- [ ] B5 「清空课表」→ 确认 → 全部消失
- [ ] B6 课表为空时上课判定不再触发（查看课表显示"课表为空"）

### C. 守护日历删改（原 Bug：写入后无法删除/更改/取消）
- [ ] C1 守护日历详情页底部有「全部日子管理」面板
- [ ] C2 点右上角「＋」添加一个日子 → 面板立即出现该条
- [ ] C3 点该条「修改」→ 预填原值 → 改标题/日期保存 → 月历与列表同步更新
- [ ] C4 点该条「删除」→ 确认 → 月历标记与列表同时消失
- [ ] C5 点日历格子选中某天 → 选中详情卡里的编辑/删除按钮仍可用（回归不破坏）
- [ ] C6 内置节日（春节等）无删除按钮、不可误删

### D. 共同记忆（原 Bug：无法查看/写入/更改）
- [ ] D1 共同记忆卡片下方有记忆列表；为空时显示写入引导
- [ ] D2 填写新记忆 → 「保存」→ 列表立即出现（含作者）
- [ ] D3 点某条「修改」→ 预填 → 改内容保存 → 立即生效
- [ ] D4 点某条「删除」→ 确认 → 消失
- [ ] D5 杀掉 App 重开 → 剩余记忆仍在
- [ ] D6 MCP 侧 add/edit/remove_shared_memory 命令写同一条数据（手机端列表可见 AI 侧改动）
