## 一、现状盘点结论（决定改造路径）

| 项 | 实际情况 |
|---|---|
| 工程形态 | Android 原生 **Java**（57+ 个 `.java`，0 个 `.kt`），`MainActivity.java` 3500 行 |
| UI 构建方式 | `activity_main.xml`（607 行 / 205 个 id）+ 大量 Java 动态构建（杂志页、日记页、日历页、抽屉、弹层） |
| 页面组织 | 4 个主 tab（今天 / 陪伴 / 守护 / 设置）+ 若干子页；不是需求单的 16 个独立页 |
| 旧主题 | `UITheme` 6 套**彩色**主题（白桃粉 / 雾蓝白 / 夜航黑 / 星云紫 / 薄荷透明 / 奶油绿），另有 97 处硬编码颜色（`#B17286` 等） |
| 换肤入口 | `MainActivity.applyVisualTheme()` → `styleTree(root, t, false)` 遍历全树着色，是全局见效的杠杆点 |
