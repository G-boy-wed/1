📘 GitHub PAT 生成教程

目的：生成一个能推送代码到 https://github.com/G-boy-wed/1.git 的令牌，发给我完成「上传 github」

⚠️ 重要提醒：令牌只会显示这一次，关掉页面就再也看不到了。复制后直接发给我即可，我不会在回复里打印明文，推送完会立刻清理本地的 token 配置。
1

打开令牌设置页

在浏览器登录你的 GitHub 账号，然后访问：
https://github.com/settings/tokens
（或：右上角头像 ▸ Settings ▸ 左侧最下方 Developer settings ▸ Personal access tokens ▸ Tokens (classic)）

2

新建令牌

点右上角绿色按钮 Generate new token，在下拉里选 Generate new token (classic)。
如果只看到 Fine-grained tokens，也先选 classic（兼容性最好）。

3

填写基本信息

• Note（备注）：随便填，如 zhangxinchuang-push
• Expiration（有效期）：建议选 7 days 或 30 days（用完可删，最安全）
• 其余可留空

4

勾选权限（最关键一步）

在 Select scopes 区域，找到并勾选：

  • ✅ repo — 整组勾上（包含对公开/私有仓库的读写，推送必须用它）
  • ⬜ workflow / admin / delete_repo — 都不用勾，不需要

如果你用的是 Fine-grained 令牌：在 Repository access 里指定 G-boy-wed/1，并在 Permissions ▸ Repository permissions ▸ Contents 设为 Read and write。

5

生成并复制

拉到页面最底部，点绿色按钮 Generate token。
新页面顶部会显示一行：github_pat_xxxxxxxxxxxx 或 ghp_xxxxxxxxxxxx。
点右边的复制图标，或直接全选复制这整串字符。

6

把令牌发给我

把复制到的那串 github_pat_... / ghp_... 直接粘贴到对话里发给我。
我收到后会执行下面的命令（你无需自己敲）：

git -c "url.https://x-access-token:<你的PAT>@github.com/.insteadOf=https://github.com/" \ push origin main

这是 fast-forward 推送，不会 force push、不会覆盖任何历史，只把 Commit M（5d804c7）接在你远端 a34dd6f 之后。

7

完成后清理（可选但推荐）

推送成功后，回到 https://github.com/settings/tokens，找到刚生成的令牌，点 Delete 删除即可，安全无忧。

✅ 准备好后，把 github_pat_... 那串令牌发我，我会立即推送并回报远端新的 HEAD 提交号。整个过程不会在对话里显示明文。

❓ 常见问题

Q：必须公开仓库才能用 PAT 吗？
A：不用。无论公开还是私有仓库，只要有 repo 权限就能推送。

Q：不想给 PAT 行不行？
A：可以。你在自己有凭据的电脑上执行 git push origin main 即可，我这边本地 Commit M 已经是完整状态。

Q：令牌泄露了怎么办？
A：立刻去 tokens 页面 Delete 删掉，旧令牌立即失效，重新生成一个新的发我就行。
