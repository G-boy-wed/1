# 掌心窗 三页横滑美化重构回执 v2026-11-21

## 本轮需求（用户明确口径）
> 不是照抄图中的软件名称，是把掌心窗内所有插件改成这个应用布局，以及可以点开进行使用更改。
> 不需要有最下方的世界/终端/守护/主题四项出现。三页横屏滑动。贴图的地方可贴图更改，可自定义背景以及自定义图标，功能必须完整正常实现。

## 实现结果

### 1. 布局严格按参考图三屏（左右横滑，无底部四项标签）
| 页 | 参考图结构 | 填充内容（掌心窗真实插件/真实数据） |
|---|---|---|
| 个人页 | 封面大卡 + 圆头像 + 名字/@账号/简介/地区 + 2×2 图标 + About me + 搜索栏 | 封面/头像/About 贴图位；名字账号简介地区可编辑；2×2 为真实插件 index 4-7 |
| 相册页 | 返回/更多 + N Photo Selected + 3 照片墙 + 4 好友头像 + 2×2 图标 + New List + 搜索栏 | 照片墙/好友头像可贴图；2×2 为真实插件 index 8-11；New List 深链课表 |
| 动态页 | 点状背景卡 + 头像 + 标题/日期 + 对话气泡 + 输入框 + 图标宫格 + 搜索栏 | 背景/头像可贴图；真实时钟/日期/天气；输入框记一句；宫格为真实插件 index 12+ |

- 三页用 `HorizontalScrollView` + 整页宽 `screenW` 实现，滑动结束吸附最近页（`snapPage`）。
- 底部只保留图里的 4 图标 Dock，且这 4 个也是真实插件（index 0-3），可点开、长按可编辑——**不再有世界/终端/守护/主题四项标签**。

### 2. 不照抄假名称，全部用掌心窗真实插件
- 唯一数据源 `DeskPluginStore.all()`（20 个真实插件，按 id 去重）。
- 分配无重复：Dock=0-3，个人页=4-7，相册页=8-11，动态页=12-末尾，恰好铺满、零重复。
- dex 校验：小红书/外卖/情侣空间/微聊/世界书/魅影/CosmicLove 计数均为 **0**。

### 3. 完整可用的自定义（全部落 SharedPreferences，持久化）
- **贴图位**：封面/头像/About/3 照片墙/4 好友头像/动态背景/动态头像共 12 个槽位。点击从系统相册选图（`ACTION_OPEN_DOCUMENT` + 长期授权），长按可更换或清除。
- **自定义背景**：每页可换背景图；或选 6 种纯色；或恢复默认渐变+星点。三页各自独立。
- **自定义图标**：每个插件长按 →「换图标」在 24 枚图标池循环；改名/改动作；前移/后移；删除；新增插件；恢复默认。
- **可编辑文案**：名字/@账号/简介/地区/动态标题，点击即改即存。
- 新增 `DeskSkinStore.java` 统一管理贴图 URI、背景、文案，空值/损坏数据安全兜底。

### 4. 修掉的自身 bug
- 深链白名单 `VALID_SECTIONS` 修正：不存在的分区统一打开设置，不再跳空白。
- 图片 URI 全部 `takePersistableUriPermission` 长期授权，重启后贴图不丢。
- 天气/时间/位置全部取真实状态（`WeatherState`/`WeatherLive`/`NowState`），失败返回 `--°`/`当前位置`，无假数据。
- 空插件列表、空贴图槽、损坏 JSON 均做兜底，不崩溃。
