## 一、分心查岗「未写入底层代码 / 运行方法错误 / 经常拉起弹窗」（已修复）
**根因**：原 `evaluateDistraction` 的 `chatArmed`（「真正开始聊天」标志）一旦在首次真实聊天后被置真就**永不重置**，导致之后任何一次切到其它 App 都被判为「切出」并触发拉回弹窗；且「每次切屏都拉回 / 累计超阈值」路径在旧标志下无去重，频繁弹窗。

**修复（重写分心状态机）**：
- 新增 `leftChat` 去重标志：**每次离开一个「真正聊过」的会话只记一次「切出」**，不会因在多个 App 间来回切换而反复累加/弹窗；
- 「切回」聊天才累计一次「切出→切回」回路，`distractLoopCount` 仅在完整回路达成阈值时触发分心查岗弹窗；
- 「看一眼就走」（停留 <20s）不计分心、清空待配对与累计；
- 所有拉回弹窗仍受 **冷却 / 安静时段 / 上课静默** 约束，彻底消除「经常拉起警告」。

## 二、天气查看 / 定位定制「查看返回不显示正确定制」（已修复）
**根因**：`WeatherState.writeLocations` / `syncLegacy` 用 `apply()`（异步）落盘，保存后立刻「查看」可能读到旧值；且查看只显示「当前地点」单条，定制内容不直观。

**修复**：
- `writeLocations` / `saveLocation` / `setCurrent` 改为 `commit()` 同步落盘，保存后立即可见；
- 「查看全部地点」改为列出**所有地点**的名称 / 城市 / 备注与「当前」标记，定制内容正确显示。

## 三、训诫板块打开时「加强管控、手机语气更加严厉」（已修复）
**修复**：
- `CompanionEmotionState.tone()`：训诫**开启且（语气=严厉 或 档位≥中）**时，原本温柔的弹窗语气强制升级为 `strict`（渲染 danger 红 + 更硬话术），人设与弹窗语气同步变严厉；
- `PolicyScheduler.strongByThreshold()`：训诫**档位≥3**时所有拉回弹窗变为「只能回到软件」不可拒绝（加强管控）；
- 陪伴话术的管束包装（`withDisciplineTone`）原已随训诫开关生效，本提交进一步在弹窗语气与强制级别上落地。

## 四、弹窗不显示在正在使用的软件上方（再次修复）
**根因**：拉回悬浮窗仅用 `FLAG_LAYOUT_IN_SCREEN`，未声明 `FLAG_NOT_TOUCH_MODAL`，卡片会吞掉当前 App 的触摸且悬浮表现不稳定。

**修复**：`PullBackOverlay` 增加 `FLAG_NOT_TOUCH_MODAL | FLAG_WATCH_OUTSIDE_TOUCH`，卡片**真正浮于当前 App 之上**、只接收自身按钮触摸、外部触摸透传给当前 App；悬浮窗优先、锁屏/无权限才退回透明 Activity 兜底（不跳转掌心窗）。

## 五、手机端修改后不写入底层代码运转（已修复）
**修复**：`PolicyStore` 全部用户侧写入（`putBool/putInt/putString` 及其全部 setter）由 `apply()` 改为 `commit()` 同步落盘，确保改完立即写入底层、调度器每个 tick 读取即生效。

## 六、课程提醒写入 bug + 课前 30 分钟弹窗提醒（已修复）
**修复**：
- 课前提醒提前量改为**读取底层配置 `PolicyStore.classRemindMin`（默认 30 分钟）**，手机端可改、改完立即生效（修复「写入 bug」硬编码 5 分钟的问题）；
- 课前提醒由「通知」升级为**「课前提醒」弹窗**（悬浮于当前 App 之上，标注类型），不打断当前界面；
- 设置页新增「课前弹窗提醒」开关 + 「课前提醒提前（分钟）」数字项，真实写入底层。

## 七、上课期间自动关闭弹窗 / 下课后自动开启（已修复）
**修复**：`PolicyScheduler.evaluate()` 检测上课状态 `ClassScheduleState.isInClassNow()`：
- 上课期间**跳过**查岗拉回 / 情绪感知 / 主动聊天 / 分心查岗 / 使用时长自动锁 / 权限提醒全部评估（弹窗自动关闭）；
- 检测到「刚进入上课」时调用 `PopupMutex.dismissAll()` **强制关闭当前任何正在显示的弹窗**；
- 课程结束 `inClass` 置否，上述评估**自动恢复**（下课后自动开启）。

## 失败点（如实）
- 分心查岗、上课静默、课前弹窗均依赖**无障碍前台包检测**与**悬浮窗权限**；若用户未开启无障碍 / 未授权悬浮窗，则降级为通知或 Activity 兜底（属系统限制，非代码 bug）。
- 弹窗「显示在当前 App 上方」在已授权悬浮窗时成立；未授权时只能以透明 Activity 兜底，视觉上仍不跳转掌心窗。
