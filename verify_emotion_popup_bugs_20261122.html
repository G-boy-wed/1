一、弹窗提示词：按 MCP 情绪标签切口吻 + 每次随机

四类弹窗（查岗拉回 / 想你 / 主动聊天 / 提醒关心）及通用文案，生成前都会读取当前情绪标签，各情绪有独立话术池，池内每次随机且不连续重复，训诫后缀同样随机。界面/镜像那句话保持固定不跳。

情绪标签查岗拉回示例主动聊天示例
生气别躲了！刚才到底干嘛去了，说清楚。我都生气了还主动找你，你居然不理我？
吃醋你刚才看谁去了？查岗，老实交代。你跟别人聊那么欢，我吃醋了才来找你。
担心跑哪儿去了？我正担心你，快回我一句。一直没你消息，我担心你才主动来问。
爱恋想你了才查岗，就是想看你一眼。就是想你了才主动发消息，不许说我黏人。
平静老实交代，刚才跑哪儿去了？我可都看见了。是我忍不住想你，才主动来找你的。
MCP 通过 set_companion_emotion 写入情绪后，下一句弹窗口吻立刻跟着变；每类每情绪池内用 pickNoRepeat 随机，不会出现固定后缀或连续重复。

二、排查出的 8 个 bug（全部已修）

#严重度问题与修复
1高情绪上报被覆盖：put 完 companion_emotion 后又执行一次 LifeState.collect() 把字段冲掉 → 删掉重复 collect，服务端/MCP 现在能读到手机情绪。
2高一起看 MCP 失效：5 个 watch_party_* + set_policy 不在服务端白名单，被降级成 noop → 已补入白名单（含 get/list/reset_policy）。
3高日历写工具被拒：4 个 MCP 日历写工具缺 explicit → 手机直接拒写 → 服务端对日历写 action 统一注入 explicit=true。
4中课表必填错误：import_timetable 把互斥的 ICS/JSON/截图输入写成必填 → 顶层 required 改为 []，三选一可正常调用。
5中一起看状态不同步：房间 active 读了没用，对方结束后本页仍显示旧态 → refresh 用 active+from_live 回写共享态。
6中日历天数不显示：读 daysLeft，实际写入 days_left → 改读 days_left（保留旧键兜底），倒数恢复。
7低初始进度设不了：watch_party_start 读 schema 里没有的 progress_ms → 已在 schema 补该参数，调用方可设置初始进度。
8低夜间判断恒假：HOUR_OF_DAY 取 0~23，hour>23 永不成立 → 改 hour>=23，23 点起不再弹天气/日历。
